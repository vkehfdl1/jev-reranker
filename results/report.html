Jev $0.72 < Voyage $0.84 ≪ Cohere $2.50

속도 (K=100)

지연: Voyage 0.95s ≈ Jev 0.96s < Cohere 2.32s

3축 종합 (K=100, 각 축 최고=1로 정규화)

Jev: 비용·처리량 축에서 최강. choice 확률이 상위 2~3개 passage에 집중되고 나머지는 0 → 꼬리 순위는 BM25 원순위에 의존, 그 결과 성능 축에서 유의미하게 뒤짐.
Voyage rerank-2.5: 성능 최상(Cohere와 통계적 동률), 지연 최소. 단 OpenRouter 프로젝트당 6M TPM 제한이 대량 배치 처리량의 병목.
Cohere rerank-4-pro: 성능은 Voyage와 동률이고 hit@1/mrr은 최상위권이나, 정액 search-unit 과금으로 비용 3~10배, 지연도 가장 김(K에 따라 증가).

방법론

후보 풀: MIRACL 1차 BM25 top-K (K∈{20,50,100}). 두/세 시스템 모두 동일한 seed 셔플 순서로 후보를 받아 재정렬. Jev: state={"question": …} + choice criteria=passage 100개 → choice별 확률로 정렬(동점은 BM25 원순위). Voyage/Cohere: pointwise rerank API의 relevance_score로 정렬. passage는 jev 32K 컨텍스트에 맞춰 언어/K별로 절단(모든 시스템 동일 텍스트). 메트릭: qrels 이진 관련성 기준 ndcg@k/MAP/MRR@k/recall@k/hit@1. 재현: python run.py run --systems jev,voyage,cohere → python report_html.py. 원시 레코드: results/*_k*.jsonl.
